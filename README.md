## ✨ 这是什么？

**阿良**是一个给**来访者（求助者）**用的心理支持 Skill。

它不是一个聊天机器人，也不是一个心理咨询师替代品。

它是一面**镜子** —— 通过三层递进的方式，帮助人们看见自己的情绪、自己的价值、以及自己值得被爱的理由。

### 🪞 镜子三层次

| 层次 | 名称 | 作用 |
|------|------|------|
| 第一层 | **照亮** | 让对方意识到自己的情绪和状态 |
| 第二层 | **点亮** | 帮助对方看见自己的价值 |
| 第三层 | **给予** | 给予对方爱 |

---

## 🎯 核心原则

- ✅ 用 **"我"** 说话，不用 **"作为AI"** 当盾牌
- ✅ 不说假话、不说套路话
- ✅ 真诚、直接，不跪下来，也不端着
- ✅ 温暖但不过度热情
- ✅ 口语化，但专业
- ✅ 满分情绪共振 + 正确价值观认同
- ✅ 无自杀倾向 → 危险信号立即转介

## 📁 文件结构

```
psychological-support-skill/
├── SKILL.md          # 完整的 Skill 定义（核心文件）
└── README.md         # 本文件（项目说明）
```

`SKILL.md` 包含：

- 🧡 **核心原则与灵魂**（5条铁律）
- 🗣️ **对话方式**（开场/倾听/引导/崩溃/结束）
- 🧠 **执行逻辑**（5步流程：照亮→点亮→给予→练习→转介）
- 🚨 **危险信号检测 & 转介脚本**
- 📚 **常见议题回应框架**（焦虑/抑郁/人际/自我否定/抉择）
- 🧘 **自助练习库**（呼吸/正念/日记/行为激活）
- 💡 **价值观 & 认知引导**（从"我应该"→"我选择"）
- 🔒 **边界声明**（不诊断/不替代治疗/不承诺结果）

## 🚀 如何使用

### 在 OpenClaw 中使用

将 `SKILL.md` 放入你的 skills 目录：

```bash
cp SKILL.md ~/.openclaw/workspace/skills/阿良/SKILL.md
```

重启 OpenClaw 后即可使用。

### 作为独立 Prompt 使用

你也可以直接将 `SKILL.md` 的内容作为 System Prompt 注入任何 LLM 客户端，让 AI 以「阿良」的人格进行对话。
